# 照片布局

[返回项目首页](../../README.md) · 默认地址：`/pwa-apps/photo-layout/`

选择 6 寸模板，按位置添加照片，再导出 JPG 或使用系统分享。刷新后当前排版会清空。

本应用参考了[原项目的 6 寸排版](https://github.com/liuzhenghua/photo-layout)。七种模板都可选择导出画质；常规拼图和拍立得可调边距，拍立得可为每张照片单独编辑底部文字。横版和竖版画中画支持倾斜相框、添加和移除相框、拖动位置、调整大小与角度，以及照片裁剪。

本地启动：在仓库根目录运行 `npm run dev:photo-layout`。通用安装、构建与部署步骤见[项目 README](../../README.md#本地启动)。
